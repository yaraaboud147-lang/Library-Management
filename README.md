# Library Management 📚

This is a small C++ project I made while learning C++ and OOP.

The idea is a simple library system with different types of books, such as paper books and ebooks.

In this project, I practiced:

- Classes and objects
- Inheritance
- Abstract classes
- Polymorphism
- Virtual functions
- Function overriding
- Pointers
- Dynamic memory
- Vectors
- Constructors and destructors

I made this project to practice OOP and understand how these concepts can be used in a simple library system.

I'm still learning C++, so I will probably improve this project and add more things to it later.

Thank you for checking out my project! ❤️
